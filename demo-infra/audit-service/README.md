# audit-service — Demo Infrastructure

This directory contains the deliberately broken fixture state for InfraPilot Scenario 3:
**silent data loss caused by a BigQuery schema mismatch**.

## The Bug

The `audit-service` emits audit events with a `user_agent` field added in a recent deploy.
The BigQuery production table was **never migrated** to include that column, causing every
`INSERT` to fail silently with a `SCHEMA_ERROR`. Zero rows are written; the service appears
healthy.

| File | State |
|------|-------|
| `schemas/emitted_audit_event.json` | ✅ Has `user_agent` field (code emits this) |
| `schemas/bigquery_table_schema.json` | ❌ Missing `user_agent` field (production table never migrated) |

## Purpose

These schema files are the **source of truth** for the FixSpec the agent generates.
When a developer triggers "Draft Remediation PR", InfraPilot's `FixSpecAgent` reads both
files and generates:

1. `scripts/validate_bq_schema.py` — compares emitted fields against BQ table fields; exits non-zero on mismatch
2. `tests/test_schema_validation.py` — pytest tests for the validation script
3. `.github/workflows/audit-schema-validation.yml` — CI workflow triggered only on changes to this directory

## Directory Layout

```
audit-service/
  README.md                          ← this file
  schemas/
    emitted_audit_event.json         ← fields the service emits (has user_agent)
    bigquery_table_schema.json       ← production BQ table schema (missing user_agent)
  scripts/                           ← generated by FixSpecAgent; empty until first draft
  tests/                             ← generated by FixSpecAgent; empty until first draft
```

## Human-in-the-Loop Flow

InfraPilot **drafts** the fix. A developer **reviews and publishes** it:

1. Run Scenario 3 investigation → completed report with schema mismatch diagnosis
2. Click "Draft Remediation PR" in the UI → FixSpec generated and stored
3. Copy the Claude Code MCP instruction from the UI
4. Paste into Claude Code (with GitHub MCP configured) → PR created on GitHub
5. Developer reviews and merges at their discretion

InfraPilot never merges or deploys automatically.
